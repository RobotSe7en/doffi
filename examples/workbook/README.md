# 工作簿协作来源示例

此目录是手工编写的 V1 工作簿包，包含 A1 的数值 4、B1 的公式 `=A1+1` 及 A1 上的指令批注。B1 保留历史导入缓存 999，当前第一方求值为 5。

[请求](../workbook.request.json)只授权修改 A1，将 B1 作为只读消费者提供；[提案](../workbook.proposal.json)将 A1 改为 10。应用前可检查 B1 当前结果变为 11，其公式及历史源保持不变。实际内容修改与批注解决一起提交，并可一起撤销。

包、请求和提案由独立数据编写，公开 API 测试核对完整冻结上下文、当前结果、原子应用及撤销。这不是 XLSX 原生输出或完整 R3 阶段验收。
