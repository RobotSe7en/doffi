# Excel 网页版名称求值观测

2026-11-09，以匿名只读 Office Web Viewer 打开本仓库已经公开、按提交 SHA 固定的合成输入。独立 Python ZIP/XML 生成器不经过 SDK；每个公式缓存故意设为 999。实际显示的 47 个值全部不同于缓存，且四个画面均未报告修复。Office 响应头版本为 `16.0.20706.42304`。

[观测记录](observations.json)包含精确公开来源、输入摘要、时间、截图摘要和逐格人工转录。[输入 XSD 检查](input-xsd.json)覆盖当前四份探针源。生成器通过 `python3 scripts/generate-excel-web-name-probes.py --check` 复核；后续只读捕获使用 `scripts/probe-excel-web.mjs --source-commit <完整公开提交 SHA>`，捕获本身不写入验收期望值。

这些截图支持名称求值行为：工作表普通名称局部优先；定义内部裸名称使用全局定义；`!名称` 只查上下文工作表的局部定义；局部定义自身的工作表决定其上下文；显式工作表名称限定可以解析全局定义。逐项结果是依据，语义描述不能扩展成未经测试的编辑行为。

本记录不代表桌面 Excel/WPS、结构编辑、合并单元格删除、原生导出或固定字体视觉验收。旧的 `workbook-calculation.xlsx` 在网页端出现修复，已排除；这里只采用最小输入的无修复画面。

追加两份同样无修复的输入：显式限定上下文 20 格、相对边界 28 格。全局动态 bang 定义经显式工作表／当前工作簿限定消费时返回 `#REF!`；局部定义仍使用自身表上下文。相对坐标按原生行列边界回绕，范围两端分别回绕后取覆盖矩形，因此跨边界范围可能覆盖整轴。这里只记录这些具体输入的实际结果，不能推导未测结构编辑。
