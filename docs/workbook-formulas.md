# 工作簿公式引用基础

R3-05 实现第一方公式解析、共享模板、引用绑定和结构映射；R3-08 增加供规则读取使用的有界只读标量内核。本页记录这些基础及读取语义；R3-09～16 的事务、增量计算、重算与输入基础已在实施，最新范围见[编辑计算交接](workbook-editing-handoff.md)，**完整函数矩阵和编辑阶段尚未完成验收**。解析成功不代表函数已经可计算。

## 语法与来源

单元格公式仍保存为分块 HTML 中的 `data-formula`。缓存值及状态继续与公式分开；AST、名称/表格绑定和共享模板都是派生状态。原始表达式不会因读取自动规范化。

[解析器](../packages/core/src/workbook/formula.ts)支持数值、字符串、布尔、错误、缺省参数、函数调用、标量运算、相对/绝对/混合 A1 引用、跨表引用、普通矩形、整行整列、名称、联合与交叉区域。函数参数逗号与引用联合逗号区分；括号保持引用运算优先级。前缀正负号、百分号和乘方遵循 Excel 的优先级和结合规则。

[结构化引用](../packages/core/src/workbook/structured-reference.ts)覆盖表名/省略表名、列/列区间、All/Data/Headers/Totals/This Row、Headers+Data、Data+Totals、`[@Column]` 简写和列名特殊字符转义。省略表名时需提供实际所属表，不能根据可见 DOM 猜测。绑定器按源表几何、列名和表头/汇总行计算至多一个矩形；空数据区显式表示为空，未知表/列和无效当前行返回相应公式错误。

相对引用保留为相对公式所在格的偏移；相同复制模板共享 AST。原生共享公式按工作表建立有界定义表，保存组号、来源坐标、声明范围和模板，不为每个跟随格常驻一棵树。重复基准、缺失基准、越界跟随及超预算明确失败。原生导入可先扫描共享定义，再逐块解析实际单元格。

原生命名公式以 A1 作为相对引用原点，不用当前选中格或活动表的位置。固定 Calc 的[独立证据](evidence/xlsx-name-semantics.json)覆盖两种选中位置/活动表、三张表和 30 个公式结果，并验证未指定工作表的引用使用调用者工作表、局部名称优先于同名全局名称。运行 `python3 scripts/check-xlsx-name-semantics.py` 核对；仅 `--record` 更新证据。该探针使用独立 ZIP/XML 输入，不代表 SDK 求值或 Excel/WPS 实机验收已通过。

跨包适配器通过 core 的 `parseWorkbookFormula`、`printWorkbookFormula` 和 `createSharedWorkbookFormulas` 使用同一实现，公开类型为本项目的只读语法树，不暴露第三方解析器。打印与原生读取不另写一份公式解析器；引用重写及表格绑定暂为核心内部工具。

`WorkbookModel.resolveReference(expression, { sheetId, row, column })` 已将静态引用绑定接入当前只读模型：支持单格/矩形/整行列、跨表、局部与全局名称、智能表、联合、交集和范围运算。名称的相对分量以调用坐标解析；显式局部名称在所属表解析。整列只返回一个区域，不生成百万条记录。联合保留重复项，交集为空返回 `#NULL!`；未知名称、缺失工作表和越界引用分别返回明确错误。

引用查询不是求值器。动态引用函数返回 `calculation-required`，名称循环返回 `circular-name`。全局名称内部引用被局部名称遮蔽的未限定名称时，暂返回 `ambiguous-name-scope`：[独立 Calc 证据](evidence/xlsx-reference-semantics.json)显示其结果会随第一张工作表变化，不能把当前活动表或调用表猜作定义上下文。该证据同时验证局部限定、联合重复计数、交集及多区域范围运算；`python3 scripts/check-xlsx-reference-semantics.py` 检查三组输入、三张表和 72 个结果。Excel/WPS 行为仍未实机验证。

## 供读取规则使用的标量内核

`createWorkbookScalarEvaluator(model, limits?)` 绑定一个不可变工作簿。`evaluate(expression, origin, { at?, signal? })` 可将原点解析出的相对模板用于另一坐标；`cell(location, { signal? })` 读取常量或从实际公式及当前依赖求值。结果带文档、修订、步数与实际读取单元格数；可用值包含合法公式错误，`unavailable` 则单独报告未实现函数、循环及尚未确定的名称作用域，不把能力缺口伪装成 `#NAME?` 或零。IF／IFERROR／IFNA 保留相应短路；AND／OR 不因已有真假结果跳过后续错误。

当前内核实现标量运算、类型转换、错误传播、上述引用绑定、常量／计算名称、IF／IFERROR／IFNA、AND／OR／NOT／TRUE／FALSE、五类 IS 检查、SUM／MIN／MAX／AVERAGE／COUNT／COUNTA／COUNTBLANK、ABS／INT／TRUNC／MOD／POWER／SQRT／ROUND／ROUNDUP／ROUNDDOWN、LEN、ROW／COLUMN／ROWS／COLUMNS。其余已选函数继续随 R3-10 实现，不因解析成功或来源缓存而宣称支持。引用中的逻辑／文本与直接函数参数分别转换；空白、公式空字符串和错误值保留类型差别。数字舍入复用通用十进制分解，另实现公式的参数与方向规则，不调用显示格式器冒充 ROUND。LEN 当前按 UTF-16 计数。

导入缓存即使标为 `valid` 也不作为本次求值的计算来源；查询不写回值、缓存状态、修订或历史。整行／整列聚合只扫描相交的实际块，隐式空白以计数表达，不枚举百万坐标。缺省每查询最多一百万步、二十五万实际单元格、128 层与 8 Mi UTF-16，单次模型窗口最多 4096 格；解析缓存另限 256 项／2 Mi UTF-16。超限或取消明确失败，`dispose()` 清理解析缓存、索引与持有的模型引用。这仍不是 R3-10 的完整计算、长链／增量算法或一万行性能验收。

[80 项独立标量探针](evidence/xlsx-scalar-semantics.json)的 ZIP/XML 来源故意带错误缓存；固定 Calc 的计算参考使用同样公式、移除缓存的独立输入，因为该生产者会保留错误缓存而忽略来源重算标志。普通检查 `python3 scripts/check-xlsx-scalar-semantics.py` 不更新证据，并核对关键结果确实已重算。70 项当前预期与生产者相同，10 项差异分别记录规范／声明依据，包括布尔拼接、数值／逻辑比较、负数平方根以及直接参数和引用参数的聚合差别。两项类型／逻辑参数边界明确保留实现声明和未实机核对状态，不能把整份记录解释为 Excel/WPS 验收。源输入还通过官方 Transitional XSD、关系审计、公开导入和包源不变检查。

每次静态查询最多产生 4096 个区域，遍历深度 128，总操作预算 100000；表列检查与交集配对也计入预算。递归名称联合即使源表达式很短，也不能指数展开后才报错。查询结果冻结，索引与名称解析缓存只属于当前不可变模型；完整计算仍按 R3-10 完成；当前图表读取已接入同一内核，显示范围见[读取验收](workbook-reading-acceptance.md)。

数组常量、溢出 `#`、普通操作数前的 `@`、外部工作簿和三维跨表范围不在本轮语法内；不能可靠解释时明确失败。普通未实现函数可保留语法及来源缓存，是否可计算和缓存何时失效由后续计算层判断。不使用 `eval`、第三方公式引擎或单元格地址字符串替换。

## 当前源规则读取

`readWorkbookRules(model, request, { signal?, yield? })` 接收带文档、修订与工作表身份的去重坐标批次。只对与这些坐标相交的规则求值；数值比较、标量表达式和双色／三色色阶按优先级返回匹配／不匹配／不可用。停止规则在匹配时停止；遇到不可求出的停止条件也不把后续结果冒充确定匹配。色阶只扫描相交的实际分块，百分位使用实际数值样本，支持数值／百分比／百分位／公式阈值，阈值倒序明确诊断。固定 Calc 的[独立 PDF 色阶探针](evidence/xlsx-color-scale-semantics.json)覆盖八种常量、重复阈值及正负混合来源；不代表 Excel/WPS 验收。

数据验证返回七类规则及仅提示规则的当前状态；列表可读取同表／跨表单行列，使用当前依赖值并保留未知成员诊断。空白单元格与公式空字符串分开，`cell` 查询保留实际空白类型，公式引用空白仍返回数值零。规则读取不拒绝来源中的违规值，也不更改缓存；正式编辑的阻止／警告执行仍在 R3-09～16。

默认整批最多 25000 个坐标、256 条相交规则、250000 次实际值读取／保留样本、500 万步、8 Mi UTF-16。标量结果报告 `steps`、`readCells` 和 `codeUnits`；查询可降低步数及剩余文本额度，规则和图表消费者累计实际内核消耗，避免跨查询绕过整批预算。单次文本额度允许为 0：纯数值／空白读取可通过，表达式自身及实际读取的文本仍计量；超限和取消整批失败。核心不拥有定时器；宿主可提供宏任务检查点，传输取消消息得以运行。结果冻结，清理求值器及批次缓存，来源、修订与历史不变。

## 引用映射

[重写器](../packages/core/src/workbook/formula-rewrite.ts)只接收表达式、旧/新位置、类型化结构变化及必要的绑定信息，不提交文档、修改历史或读取宿主数据。

| 操作 | 行为 |
| --- | --- |
| 复制 | 调整相对分量；绝对分量和字符串常量不变；越界产生 `#REF!` |
| 插入行列 | 起点之后的引用移动；范围内部插入扩大范围；`$` 不阻止结构映射 |
| 删除行列 | 相交范围收缩；完全删除的引用产生 `#REF!`；不裁成错误的包围框 |
| 剪切移动 | 单格及矩形引用跟随数据；部分移动按用户决定拆为精确多区域；跨表保留正确限定 |
| 排序 | 用户决定区域外公式保持地址；区域内公式随记录搬移并调整相对分量；批注跟随数据由后续锚点层实现 |
| 工作表改名/删除 | 映射显式与隐式作用域；删除产生 `#REF!`；字符串文字不改变 |
| 表格/列改名 | 使用名称绑定与结构化引用节点；不误改相似名字或字符串；裸表名需确认绑定，省略表名的列引用需所属表 |

剪切拆分按矩形计算，与区域实际格数无关；重叠目标去掉重复覆盖。整行整列也不展开为百万个点。新增片段及最终表达式受预算限制，超限整项失败。把当前行表格公式剪切到表外时，使用原表几何绑定具体来源行，保留数据引用；不能把目标行误当原记录。普通结构化列引用仍绑定其表。

不受影响的公式保留原始字符串，避免一次小结构编辑仅为了格式规范化而重写整本分块。需要修改时使用带括号的规范输出并重新解析校验。跨表范围一端越界时，另一端仍保留工作表限定。

工作表改名／删除及普通区域行列插删已接入同一工作簿事务；结构引用重写保留历史缓存正文并标记过期，当前计算独立求值。行列命令的维度、规则、打印及宿主批注基础、独立 Calc 实际操作证据和未接通的组合见[行列插删](workbook-model.md)。智能表、上下文名称、剪切、排序和原生对象／批注的完整联动仍在 R3-09～16 实施，不能把纯映射器或普通区域检查计为全部验收。它们不授予宿主写权限，也不绕过候选整批校验。

## 预算与验证

公式源码最多 8192 UTF-16 单位，token/节点限制 4096，解析与输出深度最多 128。左结合长链也检查实际 AST 深度。工作簿模板和原生共享组各有累计预算；来源失败不留下半个模板。数字标量的词法与整行引用区分，不能把 `1e0:3` 悄悄改成 `1:3`。

93 个针对性测试覆盖分块/模型、解析、输出、共享组、表格绑定和引用映射；其中原生来源检查处理 16 个独立源及其 Calc 重存的四万余个公式/引用表达式，包括一万行样例、共享公式、表计算列、验证、图表及打印名称。独立点映射检查剪切重叠与删除边界，不只比较重写器自己的中间结构。类型和包依赖边界检查通过。测试不宣称计算结果或 SDK 原生导入已通过。
